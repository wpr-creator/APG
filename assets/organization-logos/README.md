# Organization identifying marks

These locally stored images identify organizations in the educational “Who Is Trying to Be Heard?” activity. They are not APG branding and do not indicate sponsorship or endorsement.

- Primary identity source: each organization’s official website listed in `who-is-trying-to-be-heard-data.js`.
- Retrieval: official-domain site icons were downloaded through DuckDuckGo’s favicon service on August 31, 2026. The YIMBY Action mark was downloaded directly from its official website.
- Display: marks are shown unchanged, at small size, beside neutral descriptions and a direct official-site link.
- Fallback: the interface retains a text abbreviation if an image cannot load.

Ownership remains with the respective organizations. Recheck an organization’s current brand guidance before reusing any mark outside this identification context.
