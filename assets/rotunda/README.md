# Rotunda artwork

`apotheosis.webp` is the Architect of the Capitol's photograph of Constantino Brumidi's 1865 fresco, *The Apotheosis of Washington*. Downloaded November 19, 2026 from the official AOC article:
https://www.aoc.gov/explore-capitol-campus/art/apotheosis-washington

Image URL:
https://www.aoc.gov/sites/default/files/styles/alternative_xl/public/2025-01/20210715_084321_SG-2000w-The-Apotheosis-Washington.jpg.webp?h=84071268&itok=Yhs8YEg3

The architecture, decorative wall illustrations, and floor pattern are original procedural artwork. The room is a stylized setting rather than an architectural survey. No images or code were taken from Krillion. The original release used the course’s existing Three.js dependency; the pixel edition renders directly in Canvas 2D.

The November 19 pixel edition uses original Canvas 2D artwork and nearest-neighbor scaling. The canopy photograph is palette-reduced at runtime to fit that artwork. Pixelify Sans is self-hosted under the SIL Open Font License in `pixelify-OFL.txt`; source: https://github.com/google/fonts/tree/main/ofl/pixelifysans .

The class-competition edition uses a course-owned weekday prompt pool. `rotunda-curriculum.json` controls the current lesson list and AP-topic cutoff. Each `rotunda-data.json` question has lesson/topic tags and a source; `scripts/audits/rotunda-notes.json` records the eight notes revisions reviewed. To add a lesson, author sourced categories in `rotunda-trivia-categories.json` and run `node scripts/build-rotunda-bank.js`. Letter categories are generated from glossary entries tagged to the currently taught lessons, through 2.3. Keep the competition ID stable so students cannot gain a second attempt. Use a new revision and future effective date, preserving the prior bank/configuration, so already-started daily sets do not change in place. Synchronize the score-service source with `node scripts/sync-apg.mjs` from `/Users/weston.rogers/Documents/Projects/APG-Rotunda-Scores`, test/deploy that service, then publish APG. Rotunda and the all-five-unit Reflecting Pool have separate banks and game state.

The cinematic edition gives each scored answer a 2.8–4.8 second camera ascent before the result card appears. Rank crossings use the shared score thresholds; reduced-motion mode and Skip ascent settle immediately. Audio is synthesized locally in `rotunda-audio.js` and muted on a first visit. No Krillion art, audio, or source code is included. The final score remains server-controlled.

The arcade pass keeps one full-width pixel-art world for prompts, ascent, and results. The title screen shows the timer and rarity rule, without lesson/topic coverage. Unrecognized nonblank guesses return `retry: true` from the score service without saving a response or extending the deadline; a correct answer, blank pass, or expired deadline ends the prompt. Explanations stay behind Other answers and the end recap.

The rendering refinement uses elapsed-time easing for the eagle and camera, with a 60 fps frame budget that falls back to 30 under sustained draw cost and retries 60 after recovery. Rear stonework, wall details, near pilasters, and motes have separate parallax rates. The motion checkbox follows the device preference until explicitly changed; a saved choice then controls both CSS and canvas effects. The leaderboard returns the completed player's round breakdown in the same snapshot as its total; all result fields refresh together, retaining open recap entries.

The detailed edition replaces the enlarged low-resolution viewport with display-resolution Canvas 2D (up to 2× device-pixel density). A cached 1800×4200 architectural illustration supplies fine wall details; the automatic ascent reveals a coffered ceiling and a 900×540 palette-adjusted fresco. The recognizable bald eagle has animated wings and carries a rolled-paper delivery. Manual pan/zoom controls and listeners are removed. The readable opening panel has one context-sensitive Start/Continue/View Results action. Results include a 0–700 height marker and interactive seven-round ascent bars; explanations remain collapsed. Existing daily identifiers and server attempts are preserved.

The November 20 trivia revision has 68 categories and 499 answer groups, each with at least three distinct correct answers. Seven shared weekday rounds progress through two baseline, three intermediate, and two advanced categories; the last uses a glossary letter. Presidents, rights, and broad government knowledge accompany AP concepts. No state/geography quizzes. Each answer has a baseline rarity (20–100 points), blended with observed frequencies using 20 prior players. Canonical names and aliases identify the same answer; ambiguous presidential surnames require a full-name choice. Typing a recognized variant offers its full canonical name without revealing untyped answers. The archived bank and previous curriculum preserve November 19 and older sessions.
