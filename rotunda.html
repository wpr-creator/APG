    How to play

    Daily climb · Monday–Friday

    • Seven prompts from the lessons covered in class. The same daily set for everyone.
    • You have 25 seconds to name one thing that fits each prompt.
    • You get one correct answer per prompt. Try another guess if an answer is not recognized. A pass or an expired timer earns no points.
    • Correct answers lift you higher. Less-used correct answers earn more leaderboard points.
    • Less-obvious answers start higher. Points adjust with today’s answer choices: 20, 40, 60, 80, or 100.
    • One scored climb per school day on this device. Clear spelling slips and equivalent wording count as the same answer.
